Sign in to Battle.net

This will create and attach a new authenticator to your account.

  1. Open the official Battle.net sign-in page and sign in there.
  2. After login, the address will contain localhost?ST=.... A 404 / File not found or unavailable-page error is expected, including when the address still starts with account.battle.net. Copy that complete address from the address bar.
  3. Return here, paste it below, and continue. After enrollment, export the OTPAuth URL for 1Password or another authenticator.

Your password is entered only on battle.net. The login token is sent from this local page to the CLI, then to Battle.net. It is not saved. Keep the CLI running.
